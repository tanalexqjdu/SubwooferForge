# SubwooferForge

SubwooferForge enables real-time, low-latency audio processing with dynamic reconfiguration and on-the-fly scaling across multi-processor platforms.

SubwooferForge is built to be simple and practical, focusing on doing one thing well.

**Why SubwooferForge?**

- SubwooferForge enables real-time, low-latency audio
- processing with dynamic reconfiguration and
- on-the-fly scaling across multi-processor platforms

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/SubwooferForge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
